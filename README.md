# Mapa Federal

**Lema:** Inteligencia territorial para empresarios y ejecutivos.

Primera versión de concepto del portal Mapa Federal.

## Qué incluye
- Portada institucional con identidad verde bosque y dorado.
- Arquitectura inicial de cinco áreas.
- Mapa exploratorio con Leaflet y OpenStreetMap.
- Buscador temático demostrativo con ubicaciones de ejemplo.
- Diseño adaptable a dispositivos móviles.

## Importante
El buscador de esta versión es una demostración basada en reglas, no un modelo de inteligencia artificial. Los lugares y descripciones son contenido ilustrativo inicial y deberán ampliarse, verificarse y vincularse a fuentes confiables antes de su uso comercial.

## Publicación
Puede publicarse con GitHub Pages desde Settings → Pages → Deploy from a branch → main → /(root).

## Dependencias externas
- Leaflet 1.9.4 (CDN)
- OpenStreetMap tiles

La disponibilidad del mapa requiere conexión a internet.
